# LD1125H 24GHz mmWave Radar Sensor

## Overview

The **Hi-Link LD1125H** is a 24GHz FMCW (Frequency-Modulated Continuous Wave) radar sensor designed for human presence detection and motion sensing. It provides UART-based communication for configuration and real-time detection data.

### Key Features

- **Frequency**: 24GHz FMCW radar
- **Detection Range**: Up to 8+ meters (configurable)
- **Interface**: UART (9600 baud default, ASCII protocol)
- **Detection Modes**: Motion detection and presence (occupancy) detection
- **Power Supply**: 5V (operates on 3.3V logic levels for UART)
- **Output**: Configurable ASCII text or GPIO high/low signal

### Hardware Architecture

- **Radar IC**: SGRSemi SRK1101 (24GHz analog radar IC - clone of Infineon BGT24LTR11N16)
- **MCU**: GigaDevice GD32F303CET6 (ARM Cortex-M4, 512KB Flash, 64KB RAM)
- **Firmware**: Closed-source Hi-Link firmware (V4.1 as of 2023)

### ESP32-S3 UART Configuration

```c
#include "driver/uart.h"

#define LD1125H_UART_NUM    UART_NUM_1
#define LD1125H_TX_PIN      16
#define LD1125H_RX_PIN      17
#define LD1125H_BAUD_RATE   9600

void ld1125h_uart_init(void) {
    uart_config_t uart_config = {
        .baud_rate = LD1125H_BAUD_RATE,
        .data_bits = UART_DATA_8_BITS,
        .parity    = UART_PARITY_DISABLE,
        .stop_bits = UART_STOP_BITS_1,
        .flow_ctrl = UART_HW_FLOWCTRL_DISABLE,
    };
    
    uart_param_config(LD1125H_UART_NUM, &uart_config);
    uart_set_pin(LD1125H_UART_NUM, LD1125H_TX_PIN, LD1125H_RX_PIN, 
                 UART_PIN_NO_CHANGE, UART_PIN_NO_CHANGE);
    uart_driver_install(LD1125H_UART_NUM, 1024, 1024, 0, NULL, 0);
}
```

## UART Protocol

### Protocol Basics

- **Encoding**: ASCII text
- **Termination**: Carriage return + line feed (`\r\n`)
- **Baud Rate**: 9600 (default)
- **Format**: 8 data bits, no parity, 1 stop bit

### Command Format

All commands are ASCII strings followed by `\r\n`:

```text
command=value\r\n
```

## Configuration Commands

### Motion Detection Thresholds

```c
// Set motion detection threshold for different distance ranges
"th1_mov=30\r\n"   // 0 to 2.8m range (default: 30)
"th2_mov=15\r\n"   // 2.8 to 8m range (default: 15)
"th3_mov=6\r\n"    // Above 8m range (default: 6)
```

### Presence (Occupancy) Detection Thresholds

```c
// Set presence detection threshold for different distance ranges
"th1_occ=30\r\n"   // 0 to 2.8m range (default: 30)
"th2_occ=15\r\n"   // 2.8 to 8m range (default: 15)
"th3_occ=6\r\n"    // Above 8m range (default: 6)
```

### Range Configuration

```c
"rmax=60\r\n"      // Set maximum detection range (default: 60 = 6.0m)
                   // Value is in decimeters (60 = 6.0m, 80 = 8.0m)
```

### Advanced Parameters

```c
"eff_th=20\r\n"    // Effective threshold ratio (default: 20%)
                   // Target must be detected eff_th% of the time to be valid

"accu_num=8\r\n"   // Chirp accumulation count (default: 8)
                   // Higher values reduce noise but increase latency

"occ_st=250\r\n"   // Occupancy chirp interval in ms (default: 250ms)
```

### Test and Output Modes

```c
// Test modes (default: 0)
"test_mode=0\r\n"  // Normal: output detection status and distance
"test_mode=1\r\n"  // Advanced: output status, distance, and signal strength
"test_mode=2\r\n"  // Debug: output occupancy signal spectrum
"test_mode=3\r\n"  // Debug: output motion signal spectrum
"test_mode=4\r\n"  // Toggle: enter/exit spot frequency mode

// Output modes (default: 0)
"opt_mode=0\r\n"   // UART output: ASCII text via serial port
"opt_mode=1\r\n"   // GPIO output: TX pin becomes GPIO, high when target detected

"led_tim=1\r\n"    // GPIO high level duration in seconds (for opt_mode=1)
```

### System Commands

```c
"get_all\r\n"      // Get all current parameter values
"save\r\n"         // Save parameters to non-volatile memory
"VER\r\n"          // Get firmware version
"update_fir\r\n"   // Enter firmware update mode
```

## C/C++ Code Examples

### Basic Command Sending

```c
#include <string.h>
#include "driver/uart.h"

void ld1125h_send_command(const char *cmd) {
    char buffer[64];
    snprintf(buffer, sizeof(buffer), "%s\r\n", cmd);
    uart_write_bytes(LD1125H_UART_NUM, buffer, strlen(buffer));
}

void ld1125h_set_max_range(uint8_t range_dm) {
    char cmd[32];
    snprintf(cmd, sizeof(cmd), "rmax=%d", range_dm);
    ld1125h_send_command(cmd);
}

void ld1125h_set_motion_threshold(uint8_t zone, uint8_t threshold) {
    char cmd[32];
    snprintf(cmd, sizeof(cmd), "th%d_mov=%d", zone, threshold);
    ld1125h_send_command(cmd);
}
```

### Reading Sensor Data

```c
typedef enum {
    LD1125H_NONE,
    LD1125H_MOTION,
    LD1125H_OCCUPANCY
} ld1125h_state_t;

typedef struct {
    ld1125h_state_t state;
    float distance;
    float strength;
} ld1125h_data_t;

bool ld1125h_read_data(ld1125h_data_t *data) {
    uint8_t buffer[128];
    int len = uart_read_bytes(LD1125H_UART_NUM, buffer, sizeof(buffer) - 1, 
                              pdMS_TO_TICKS(100));
    
    if (len <= 0) return false;
    
    buffer[len] = '\0';
    
    // Parse "mov, dis=X.XX" or "occ, dis=X.XX"
    if (strstr((char*)buffer, "mov")) {
        data->state = LD1125H_MOTION;
        sscanf((char*)buffer, "mov, dis=%f", &data->distance);
        return true;
    } else if (strstr((char*)buffer, "occ")) {
        data->state = LD1125H_OCCUPANCY;
        sscanf((char*)buffer, "occ, dis=%f", &data->distance);
        return true;
    } else if (strstr((char*)buffer, "none")) {
        data->state = LD1125H_NONE;
        data->distance = 0.0f;
        return true;
    }
    
    return false;
}
```

### Complete Example with FreeRTOS Task

```c
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "esp_log.h"

static const char *TAG = "LD1125H";

void ld1125h_task(void *pvParameters) {
    ld1125h_uart_init();
    
    // Configure sensor
    vTaskDelay(pdMS_TO_TICKS(1000));  // Wait for sensor boot
    ld1125h_send_command("th1_mov=40");
    vTaskDelay(pdMS_TO_TICKS(100));
    ld1125h_send_command("th1_occ=35");
    vTaskDelay(pdMS_TO_TICKS(100));
    ld1125h_send_command("rmax=80");  // 8.0 meters
    vTaskDelay(pdMS_TO_TICKS(100));
    ld1125h_send_command("save");
    
    ESP_LOGI(TAG, "LD1125H configured");
    
    ld1125h_data_t sensor_data;
    
    while (1) {
        if (ld1125h_read_data(&sensor_data)) {
            switch (sensor_data.state) {
                case LD1125H_MOTION:
                    ESP_LOGI(TAG, "Motion detected at %.2f meters", 
                             sensor_data.distance);
                    break;
                case LD1125H_OCCUPANCY:
                    ESP_LOGI(TAG, "Presence detected at %.2f meters", 
                             sensor_data.distance);
                    break;
                case LD1125H_NONE:
                    ESP_LOGI(TAG, "No target detected");
                    break;
            }
        }
        
        vTaskDelay(pdMS_TO_TICKS(100));
    }
}
```

## Tips for C/C++ Programmers

### 1. **UART Buffer Management**

The sensor outputs data continuously. Use a ring buffer or queue to prevent data loss:

```c
#define RX_BUF_SIZE 256
QueueHandle_t uart_queue;
uart_driver_install(LD1125H_UART_NUM, RX_BUF_SIZE * 2, 0, 10, &uart_queue, 0);
```

### 2. **Line Buffering**

Parse complete lines (terminated by `\r\n`) to avoid partial reads:

```c
static char line_buffer[128];
static int line_pos = 0;

void process_uart_byte(char c) {
    if (c == '\n' && line_pos > 0 && line_buffer[line_pos-1] == '\r') {
        line_buffer[line_pos-1] = '\0';  // Null terminate
        parse_sensor_data(line_buffer);
        line_pos = 0;
    } else if (line_pos < sizeof(line_buffer) - 1) {
        line_buffer[line_pos++] = c;
    }
}
```

### 3. **Configuration Timing**

Wait at least 100ms between configuration commands for sensor to process:

```c
ld1125h_send_command("th1_mov=40");
vTaskDelay(pdMS_TO_TICKS(100));
ld1125h_send_command("save");
```

### 4. **Error Handling**

Monitor for unexpected output or timeouts:

```c
int timeout_counter = 0;
if (!ld1125h_read_data(&data)) {
    timeout_counter++;
    if (timeout_counter > 50) {  // 5 seconds at 100ms intervals
        ESP_LOGW(TAG, "Sensor timeout, reinitializing...");
        ld1125h_uart_init();
        timeout_counter = 0;
    }
}
```

### 5. **Power-On Initialization**

Sensor requires ~1 second boot time after power-on before accepting commands.

## Troubleshooting

| Issue                          | Solution                                           |
| ------------------------------ | -------------------------------------------------- |
| No data received               | Check TX/RX crossover, baud rate, power supply     |
| Garbled data                   | Verify baud rate is 9600, use 3.3V logic levels    |
| Detection too sensitive        | Increase threshold values (th1_mov, th1_occ)       |
| Detection not sensitive enough | Decrease threshold values                          |
| No long-range detection        | Increase `rmax`, decrease `th3_mov`/`th3_occ`      |
| False positives                | Increase `eff_th`, increase `accu_num`             |
